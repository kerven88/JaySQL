登录后第一屏，用于快速掌握全局状态：有多少实例、多少待办、哪些风险需要立刻处理。

## 概览卡片

| 卡片 | 展示内容 | 数据来源 |
| --- | --- | --- |
| 实例总数 | 按引擎 / 环境分布 | 实例登记表 |
| 今日备份 | 成功 / 失败 / 运行中数量 | 备份执行记录 |
| 活跃告警 | 按 P0~P3 分级计数 | 告警事件表 |
| 待我审批 | 需要当前用户处理的工单 | 工单与审批流 |

## 待办与风险

**待办**是需要你动手的事：

- 待我审批的工单
- 失败或超时的备份任务
- 待处理的告警

**风险**是系统判断"迟早出事"的项：

- 长期未备份 / 备份失败多日
- 从未做过恢复演练
- 实例健康分持续偏低
- 慢 SQL 数量突增

风险项支持**忽略**（带过期时间），忽略后不再计入统计，过期会自动回到列表。

:::info 卡片数量不对？
首页卡片按权限裁剪：没有某模块权限的用户看不到对应卡片，这不是加载失败。
另外"待我审批"只统计审批流中**当前节点指向你**的工单，已流转给别人的不会出现。
:::

## 快捷入口

首页提供常用操作直达：SQL 查询、新建工单、新建备份任务、数据恢复、告警中心。

## 怎么用它做日巡检

一个实用的顺序：

```text
1. 看活跃告警：有没有 P0/P1 未恢复
2. 看今日备份：失败的是哪个任务、是不是连续失败
3. 看风险项：新增了什么、昨天忽略的是否过期
4. 看待我审批：别卡住别人的变更
```
