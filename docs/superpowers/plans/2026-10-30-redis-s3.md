# Redis instance management and S3 storage targets

Goal: Register/edit/test/probe Redis endpoints, and enable existing S3-compatible backup storage end to end.

Scope: Redis is managed as an instance only, with optional password / ACL username and TLS, default port 6379. No Redis SQL console, metrics or backup engine is implied. S3 uses existing S3_MINIO storage type and SigV4 client; expose AWS S3 / MinIO / compatible endpoints without schema migration. Preserve all pending Telegram and README changes.

- [x] Add frontend Redis type, optional auth, TLS settings, default port and appropriate display; verify rendered creation/editing.
- [x] Expose S3 target choice, clear AWS/MinIO guidance, defaults, and verify existing precheck/upload behavior with tests.
- [x] Run affected backend tests, frontend production build and independent review; update documentation.

Redis probe design: a bounded RESP2 connection checker using AUTH/PING only, standard library net/tls, no general Redis query client. TLS verifies hostname/certificate using system trust. Redis credentials optional; existing non-Redis required rules preserved. Metadata synchronization is explicitly unavailable for Redis, scheduler skips it. Edit keeps password by default, with an explicit Redis-only clear action. Reusing saved Redis credentials for test payloads must keep the saved endpoint/user unchanged.

Validation: all common, backup, notifier and monitor package tests passed. Production frontend build and Go 1.23.12 Linux amd64 build passed. Mocked-browser checks covered Redis no-auth create, TLS edit test with saved credential ID, explicit password clear, and S3 selection/fields/precheck/save. Local protocol mock tests covered Redis AUTH/PING/timeout/TLS rejection and S3 precheck/multipart upload/readback; no live Redis or cloud credentials were used. Independent review caught Redis post-write SQL metadata synchronization and Unicode ciphertext capacity issues; both were fixed with regression tests. Username/password columns expand through existing AutoMigrate; no new storage enum is introduced.
